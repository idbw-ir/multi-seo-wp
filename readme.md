## معرفی

**Multi Language SEO System** یک افزونه قدرتمند وردپرس است که به شما امکان می‌دهد تنظیمات SEO را به صورت مجزا برای هر زبان و هر نوع پست (Post Type) مدیریت کنید. این افزونه به صورت خودکار عنوان، توضیحات متا و کلمات کلیدی را بر اساس الگوهای تعریف شده به افزونه‌های سئو Yoast و Rank Math اعمال می‌کند.

این افزونه با **Polylang** برای مدیریت چندزبانگی و با **Yoast SEO** و **Rank Math** برای مدیریت SEO سازگار است.

## ویژگی‌ها

### 🌐 پشتیبانی چندزبانه
- مدیریت SEO برای هر زبان به صورت مستقل
- سازگاری کامل با افزونه **Polylang**
- تشخیص خودکار زبان پست

### 🔍 سازگاری با افزونه‌های SEO
- پشتیبانی از **Yoast SEO**
- پشتیبانی از **Rank Math**
- تشخیص خودکار افزونه فعال

### ⚙️ پنل تنظیمات پیشرفته
- تنظیمات جداگانه برای هر Post Type
- تنظیمات مجزا برای هر زبان
- پشتیبانی از تنظیمات آرشیو (Archive)
- رابط کاربری ساده و فارسی

### 🔄 ذخیره خودکار
- اعمال خودکار تنظیمات هنگام ذخیره پست
- جلوگیری از بازنویسی مقادیر دستی
- علامت‌گذاری مقادیر تولید شده توسط سیستم

### 📝 متغیرهای پویا
- پشتیبانی از Placeholders استاندارد
- پشتیبانی از Custom Fields
- جایگزینی خودکار متغیرها

## نصب

### روش اول: نصب دستی

1. فایل افزونه را دانلود کنید
2. پوشه `multi-seo` را در مسیر `wp-content/plugins/` آپلود کنید
3. از منوی **افزونه‌ها** در پیشخوان وردپرس، افزونه را فعال کنید

### روش دوم: آپلود از پیشخوان

1. فایل ZIP افزونه را دانلود کنید
2. به مسیر **افزونه‌ها > افزودن > بارگذاری افزونه** بروید
3. فایل ZIP را انتخاب و نصب کنید
4. افزونه را فعال کنید

## پیکربندی

پس از فعال‌سازی افزونه:

1. به مسیر **تنظیمات > SEO چندزبانه** بروید
2. برای هر Post Type و هر زبان، تنظیمات زیر را وارد کنید:

### فیلدهای موجود

#### تنظیمات پست (Single Post)
- **عنوان SEO**: الگوی عنوان سئو (مثال: `%title% | %sitename%`)
- **کلمه کلیدی فوکوس**: کلمه کلیدی اصلی پست
- **توضیحات متا**: توضیحات متا برای موتورهای جستجو

#### تنظیمات آرشیو (Archive)
- **عنوان آرشیو**: عنوان صفحه آرشیو
- **توضیحات آرشیو**: توضیحات متا برای صفحه آرشیو

### مثال پیکربندی

برای Post Type `product` در زبان `fa`:

```
عنوان SEO: %title% | فروشگاه %sitename%
کلمه کلیدی فوکوس: محصول دیجیتال
توضیحات متا: %title% - بهترین قیمت در %sitename%. %customfield(short_description)%
عنوان آرشیو: محصولات %sitename%
توضیحات آرشیو: مشاهده و خرید انواع محصولات دیجیتال
```

## متغیرهای قابل استفاده

افزونه از متغیرهای زیر در الگوهای SEO پشتیبانی می‌کند:

### متغیرهای استاندارد

| متغیر | توضیحات | مثال خروجی |
|-------|---------|------------|
| `%title%` | عنوان پست | محصول دیجیتال |
| `%sitename%` | نام سایت | فروشگاه من |
| `%posttype%` | نام Post Type | محصولات |

### متغیرهای Custom Field

برای دسترسی به Custom Fields از الگوی زیر استفاده کنید:

```
%customfield(meta_key)%
```

**مثال:**
```
%customfield(price)%
%customfield(short_description)%
%customfield(sku)%
```

### ترکیب متغیرها

می‌توانید متغیرها را با هم ترکیب کنید:

```
%title% - %customfield(brand)% | %sitename%
```

## ساختار افزونه

```
multi-seo/
├── multi-seo.php              # فایل اصلی افزونه
├── includes/
│   ├── class-multi-seo.php    # کلاس اصلی افزونه
│   ├── class-admin.php        # مدیریت پنل تنظیمات
│   ├── class-seo-compatibility.php  # سازگاری با Yoast/Rank Math
│   └── functions.php          # توابع کمکی
├── languages/                 # فایل‌های ترجمه
└── uninstall.php              # حذف تنظیمات هنگام حذف افزونه
```

### توضیحات فایل‌ها

- **multi-seo.php**: نقطه ورود افزونه، تعریف ثابت‌ها و بارگذاری فایل‌ها
- **class-multi-seo.php**: مدیریت همگام‌سازی SEO و آرشیوها
- **class-admin.php**: ایجاد منو و فرم تنظیمات
- **class-seo-compatibility.php**: سازگاری با Yoast و Rank Math
- **functions.php**: توابع کمکی و Placeholders

## توسعه

### هوک‌های موجود

#### Action Hooks

```php
// پس از همگام‌سازی SEO
do_action('ms_after_sync_seo', $post_id, $plugin);

// پس از همگام‌سازی آرشیو
do_action('ms_after_sync_archive', $post_types, $langs);
```

#### Filter Hooks

```php
// تغییر متغیرهای قابل استفاده
apply_filters('ms_available_placeholders', $placeholders);

// تغییر فیلد مپ SEO
apply_filters('ms_seo_field_map', $field_map, $plugin);
```

### افزودن پشتیبانی از افزونه SEO جدید

برای افزودن پشتیبانی از یک افزونه SEO جدید:

1. در فایل `class-seo-compatibility.php`، متد `get_active_plugin()` را ویرایش کنید
2. متد `get_field_map()` را برای افزونه جدید به‌روزرسانی کنید
3. فیلترهای لازم را اضافه کنید

## سوالات متداول

### آیا این افزونه با WPML سازگار است؟

در حال حاضر این افزونه فقط با **Polylang** سازگار است. پشتیبانی از WPML در نسخه‌های آینده اضافه خواهد شد.

### آیا تنظیمات دستی SEO بازنویسی می‌شوند؟

خیر. اگر برای یک پست، عنوان یا توضیحات متا را به صورت دستی وارد کرده باشید، افزونه آن را بازنویسی نمی‌کند.

### چگونه متغیرهای جدید اضافه کنم؟

می‌توانید از فیلتر `ms_available_placeholders` استفاده کنید یا مستقیماً در فایل `functions.php` متد `ms_replace_placeholders()` را ویرایش کنید.

### آیا این افزونه بر عملکرد سایت تأثیر می‌گذارد؟

خیر. افزونه فقط هنگام ذخیره پست و در صفحه تنظیمات اجرا می‌شود و تأثیری بر سرعت سایت ندارد.

## عیب‌یابی

### تنظیمات SEO اعمال نمی‌شوند

1. بررسی کنید که افزونه Yoast یا Rank Math فعال است
2. بررسی کنید که Post Type مورد نظر در تنظیمات افزونه موجود است
3. کش مرورگر و کش سایت را پاک کنید

### متغیرها جایگزین نمی‌شوند

1. نام متغیر را بررسی کنید (باید دقیقاً مطابق باشد)
2. برای Custom Fields، مطمئن شوید که meta key صحیح است
3. لاگ‌های خطا را بررسی کنید
